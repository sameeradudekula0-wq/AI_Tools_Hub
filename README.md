# AI Tools Hub

A centralized directory and recommendation platform for discovering AI tools.

## Project structure

- `frontend/` — React user interface
- `backend/` — Flask API and recommendation logic
- `dataset/` — AI tools dataset
- ## Features

- Explore AI tools in one place.
- Search for AI tools.
- Browse categorized AI tools.
- User-friendly and responsive interface.

## Technologies Used

- React.js
- JavaScript
- Python
- Flask
- HTML
- CSS
